# Simple Bank System

A console-based banking management system written in C++.

## Features

- Creating bank customers
- Automatic customer ID generation
- Creating bank accounts for existing customers
- Automatic bank account number generation
- Depositing money
- Withdrawing money
- Preventing withdrawals above available balance
- Transferring money between accounts
- Displaying customer list
- Displaying account list
- Displaying account details
- Displaying transaction history
